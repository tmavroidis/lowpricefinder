# Low Price Finder

Find the lowest price on a product by scanning its UPC barcode.

## Features

- **Barcode Scanning**: Quickly scan any product UPC code.
- **Price Comparison**: Instantly search for the product on Google Shopping and Amazon to find the best deal.
- **Easy to Use**: Simple interface designed for quick scanning while shopping.

## Getting Started

1. Launch the app.
2. Tap the "Scan Product Barcode" button to use your device camera.
3. Alternatively, tap "Enter Code Manually" to type in a UPC code.
4. Align the barcode within the guide box (if scanning).
5. Choose a platform (Google Shopping or Amazon) to compare prices.

## Desktop Support
This app is compatible with Windows, macOS, and Linux. Ensure your device has a functional camera for the scanning feature. On macOS, camera and network permissions are pre-configured in the entitlements files.

## Development

This project uses:
- `mobile_scanner` for barcode recognition.
- `url_launcher` for opening web searches.
